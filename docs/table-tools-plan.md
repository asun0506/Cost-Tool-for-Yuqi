# 表格工具栏实施计划

目标：本地成本工具内所有 HTML 表格具备筛选、隐藏行列、单元格格式及行高列宽设置。

沿用单文件离线架构。在统一入口监听新生成的表格，为页面、弹窗和预览附加相同工具栏。以项目、页面、配置、表头和行标识隔离显示偏好；本机保存。格式及筛选不修改业务记录，不改变成本计算、原始文件和导出内容。

交互：点击单元格选择，Shift 点击选择矩形区域；点击表头选择整列。工具栏可选单元格/选区、整行、整列或整表，提供字体、字号、填充色、字色、左中右对齐、行高、列宽。按任意列筛选，条件可组合；支持隐藏行列、恢复全部、清除筛选、重置格式。

实施顺序：

1. 增加统一的表格增强、状态与格式应用函数，保留现有按钮和表单行为。
2. 增加紧凑工具栏、选区与尺寸控件；适配弹窗及无表头、空表、跨列表格。
3. 检查筛选/隐藏、范围格式、尺寸、刷新恢复及配置隔离；运行现有业务回归与单文件检查。
4. 更新使用说明，刷新脚本安全哈希并同步离线首页。
