# 单车 BOM 成本工作台

离线运行的单文件网页工具，用于 EBOM / Cost BOM 版本管理、车型成本看板、成本变更、风险、锁板和周报。当前为 **v0.1.0 开发初版**。

## 使用

1. 下载 [`dist/cost-bom-tool.html`](dist/cost-bom-tool.html)，用支持 Web Crypto 的现代浏览器打开。
2. 打开后直接进入本机工作区，创建项目与高、中、低配，无需设置或输入密码。
3. 导入 EBOM 确定零件、配置与用量；再导入 Cost BOM 补充成本信息。两类导入均可选填“版本日期”，留空默认当天。补传历史文件时按版本日期参与首页阶段对比，实际上传时间独立保留；较早的版本不会覆盖较新的当前状态。历史 Cost BOM 需要对应日期或更早的 EBOM 结构。
4. 检查差异并确认价格选择，维护成本变更，查看首页成本看板。
5. 定期点击“工作区备份”导出 JSON 文件，通过“恢复备份”导入。旧版加密工作区可用“导入旧工作区”输入旧密码一次性迁移，旧加密备份也可恢复。

运行工具无需安装 Node.js、无需启动服务器或联网。若浏览器禁止持久存储，应按页面提示手动下载工作区备份。XLSX 解压依赖浏览器 `DecompressionStream`；不支持时改用 CSV。

## 腾讯云部署

仓库包含默认首页 `dist/index.html`，内容与离线文件 `dist/cost-bom-tool.html` 完全一致。部署后直接访问域名首页即可进入成本工作台。

保持部署配置：目标目录 `./`、构建产物目录 `./dist`、部署路径 `/`。安装命令与构建命令均可留空，无需依赖或服务器。若已填写 `npm run build`，也支持重新生成默认首页。

## EBOM / Cost BOM 工作流

侧边目录分为三个板块：成本总览（成本周报）、核心数据管理（Cost BOM管理、EBOM 基线管理、成本变更管理、成本风险管理）、记录追溯（锁板记录、操作记录）。沿用深色导航与青绿色强调，通过分组标题、间距和细分隔线区分职能。成本周报集中展示实时看板和已保存周报快照，支持生成、预览和打印；不再提供独立的可视化看板页面。锁板记录管理导入版本与手动成本快照。

- **EBOM管理**：导入参考表中的全部工程维度和低/中/高配 S/O/-。页面以只读方式展示最新版明细及相对前版的新增、移除、用量、配置和属性变化，作为生成 Cost BOM 清单的数据源；筛选、隐藏、填色和调整列宽仅影响表格呈现，不修改 EBOM 数据。
- **Cost BOM**：统一入口内含“成本明细”和“版本与对比”页签，可导入价格、下载模板、查看历史差异与原文件。结构以最新版 EBOM 为准，按配置切换。公共“用量”与“计入单车用量”分开呈现；S 按公共用量计入，O 仅显示单价，- 不计入。一级领域、二级领域为独立列。
- **导入成本**：自动带入相同和新增信息；价格有差异时逐项选择原价或导入价，未确认前不能入库。重复上传相同源表时沿用已确认价。领域字段有变化（包括明确清空）时自动更新，源表未变则保留当前值。
- **版本与锁板**：每次确认导入都会保存只读版本、原始文件和 change log；历史版本可查看差异与原表、下载原文件。Cost BOM 差异可按完整变更号关联成本变更项，并区分“仅追溯”与“已计入BOM”。手动修改单价或领域也会记录前后值。
- **简化导入**：参考模板自动识别；无法识别时才展开字段设置，同模板后续复用已保存设置。可下载包含两级领域的 Cost BOM 模板；当前配置导出保留参考表列及工程维度。

## 表格显示工具

Cost BOM管理、EBOM基线管理、成本变更管理和成本风险管理的表格提供“表格工具”，可通过表头下拉选择升序或降序，并在工具栏恢复原顺序；排序仅影响显示。成本周报不显示表格工具。

- **选择与填充**：表格顶部和左侧显示列标与行号。点击单元格选择，按住 Shift 再点击可选择矩形区域；点击列标或行号选择整列或整行。点击填充图标应用当前预设颜色，使用旁边的下拉箭头选择颜色；“清除填充”可清除选区或当前表格的全部填充。
- **筛选**：点击表头旁的 ▾，搜索并勾选要显示的值。不同列的筛选条件叠加；可单独清除某列筛选，也可用工具栏一键清除全部筛选。筛选只影响显示，不改变成本合计。
- **隐藏与展开**：选中行或列后右键选择隐藏；点击表格中相邻位置的“+”展开，也可在工具栏的“已隐藏”区域逐项或全部展开。
- **列宽**：拖动表头右边缘调整列宽。
- **查找**：点击工具栏右侧“查找”，在弹窗输入内容，使用上一个、下一个或 Enter 在当前可见的匹配单元格间跳转。

显示设置按项目、页面、配置和表格保存在当前浏览器。它们不修改 BOM、价格、锁板或审计数据，不随工作区 JSON 备份、原文件下载或 CSV 导出。浏览器不允许保存时，工具栏会提示仅临时保存。

## 当前计算规则

- 最新 EBOM 决定零件结构、配置和公共用量；Cost BOM 导入不覆盖该结构。
- 导入 Cost BOM 时无需选择统一价格状态。仅有目标成本、没有定点及当前价格时，自动以目标成本作为预估单价；有定点价格或当前价格时自动显示正式价。零价格有效，空价格不会按零价处理。在成本明细“当前价格”单元格内点击“修改状态”，可对当前配置手动选择预估价、正式价或恢复自动判定；状态变更保留审计，不改变单价。
- **S 标配**：使用公共“用量”并计入单车合计；**O 选配**：展示单价但不计入标配合计；**- 不配**：用量为 0。
- “是否已进入 Cost BOM”为“否”的变更按配置叠加，优先取落地 Δ，否则取预算 Δ；为“是”的不再叠加。保存包含状态不会自动写入或修改 BOM 价格。
- **last stage** 为首页所选日期当天结束时的历史状态，默认七天前；**current stage** 可选截止日期，留空或选择今天时取最新状态；选择历史日期时，成本和变更统计截至该日期日末，且不得早于 last stage。阶段日期按项目保存。历史成本根据版本、价格和操作记录还原，资料不足显示“无法还原”或 —。
- 单车 Δ 直接求和；零件单价 Δ 乘以对应装车用量。涨价填正数，降价填负数。
- 首页 Review 和配置明细按 **二级分类** 汇总，空分类归入“未分类”。
- Review 的目标柱只统计 BOM 零件目标成本。各类瀑布块监控基准日期日末之后至当前的变更，包含已入及未入 BOM 的变更；BOM 导入、用量与其他调价造成的未归因净变化单列“其他差异”，使瀑布图与实际成本净变化一致。缺少变更金额或用量时提示待补充。
- 首页“最新成本变更”数量按变更日期筛选同一期间，配置金额按期间已记录变更的价差汇总（包含已入及未入 BOM），不依赖历史 Cost BOM 是否完整；历史基准不足时，仅阶段成本对比保持缺失提示。生成周报默认使用首页的 last stage 和 current stage 日期，current stage 留空时以生成时最新状态为终点，保存基准成本、当前成本、期间净变化及变更明细。

## 开发与验证

应用源码和离线交付物为 `dist/cost-bom-tool.html`。运行 `npm run build` 将其同步为部署首页 `dist/index.html`；两者均可独立离线运行。测试直接提取交付 HTML 内的脚本，避免测试到过期副本。

```bash
npm test
```

表格工具栏另提供真实浏览器交互检查：`npm run test:tables`。检查使用临时浏览器配置和合成数据，验证表头筛选、查找跳转、填充、隐藏展开、拖动列宽、持久化及各页面接入；需本机安装 Chrome / Edge，也可通过 `TABLE_TEST_BROWSER` 指定 Chromium 可执行文件。

需要 Node.js 18 或以上版本，无第三方 npm 依赖。修改脚本后运行以下命令刷新 CSP 脚本哈希，再测试：

```bash
node scripts/check-standalone.cjs --update-csp
npm run build
npm test
```

- `tests/`：BOM 工作流、Δ 计算和二级分类回归检查。
- `scripts/`：单文件结构、脚本语法、CSP 检查。
- [`docs/STATUS.md`](docs/STATUS.md)：已实现范围、验证证据、待验收项。
- 早期内部设计稿与工作计划保留在本地，不纳入公开仓库；当前实现范围以代码和状态文档为准。

## 数据存储

工作区无需密码，打开后自动读取本机数据。工作区保存在浏览器 IndexedDB 中，JSON 备份、可读表格和周报均为明文。旧版加密数据保留在独立存储键中，不会被新工作区覆盖；导入旧数据仍需原密码。应用的 CSP 禁止外部连接和脚本资源。

仓库只保存代码、合成测试数据及文档，不包含实际 BOM、会议截图、上传文件或工作区备份。当前仍需使用脱敏原始 Excel 和目标公司浏览器验收；测试通过不等于已完成生产验收。

## 风险清单

风险可多选影响的车型配置，列表默认展示最新进度与日期，历史进度按需展开。主页“未关闭成本风险”显示所有未关闭且未删除风险的总数，最多展开3条；先按高、中、低排序，同等级按各配置中最高的潜在价差Δ降序排列，不将不同配置金额混加。主行显示描述、责任人与等级，次行以零件名称及“配置+带符号价差”单行展示，超长内容可悬停查看。支持编辑基本信息、追加进度、删除及恢复；编辑不覆盖进度记录。删除项不参与首页、风险汇总与新生成周报，历史周报快照保持不变。旧记录未指定配置时显示“未指定”，可通过编辑补充。

新增风险分为风险概况、影响范围、进度追踪三个板块。录入日期默认当天，可修改；旧风险编辑时默认带入创建日期。表单采用紧凑对齐布局，责任人与当前进度并排展示，常规单零件录入尽量一屏完成；多零件及小屏场景保留滚动。支持多个涉及零件；零件号选填，填写后按 Cost BOM 自动匹配名称。勾选车型配置后，各零件按配置填写相对原价格的潜在价差Δ（元/车，正为涨价、负为降价），首页、清单汇总和周报统一显示带正负号的金额，按配置分别代数求和并展示，不将不同配置金额混加。旧版统一金额保留，编辑时可补充名称和各配置金额。风险表格与表格工具共享一套列设置，默认铺满容器。风险等级（高、中、低）和状态（跟进中、已解决）可在清单下拉框中直接切换，每次实际变更都会保存日期与修改前后值到审计记录，并同步更新汇总；当前进度、历史进度、编辑页面和新生成周报仅展示手动录入的进展，已有的自动操作记录也不参与进度展示与计数。追加进度窗口以新增进展为主，已录入进度默认折叠，展开后可紧凑编辑日期和内容；新增内容可留空以单独维护历史，点击删除后条目直接移出列表，不提供撤销删除选项，统一保存后生效。保存后同步更新当前进度、历史数量及新生成周报，修改和删除保留原始值与审计记录，不改变风险状态或等级。
