# 单车 BOM 成本工作台

离线运行的单文件网页工具，用于 EBOM / Cost BOM 版本管理、车型成本看板、成本变更、风险、锁板和周报。当前为 **v0.1.0 开发初版**。

## 使用

1. 下载 [`dist/cost-bom-tool.html`](dist/cost-bom-tool.html)，用支持 Web Crypto 的现代浏览器打开。
2. 打开后直接进入本机工作区，创建项目与高、中、低配，无需设置或输入密码。
3. 导入 EBOM 确定零件、配置与用量；再导入 Cost BOM 补充成本信息。
4. 检查差异并确认价格选择，维护成本变更，查看首页成本看板。
5. 定期点击“工作区备份”导出 JSON 文件，通过“恢复备份”导入。旧版加密工作区可用“导入旧工作区”输入旧密码一次性迁移，旧加密备份也可恢复。

运行工具无需安装 Node.js、无需启动服务器或联网。若浏览器禁止持久存储，应按页面提示手动下载工作区备份。XLSX 解压依赖浏览器 `DecompressionStream`；不支持时改用 CSV。

## 腾讯云部署

仓库包含默认首页 `dist/index.html`，内容与离线文件 `dist/cost-bom-tool.html` 完全一致。部署后直接访问域名首页即可进入成本工作台。

保持部署配置：目标目录 `./`、构建产物目录 `./dist`、部署路径 `/`。安装命令与构建命令均可留空，无需依赖或服务器。若已填写 `npm run build`，也支持重新生成默认首页。

## 当前计算规则

- 最新 EBOM 决定零件结构、配置和公共用量；Cost BOM 导入不覆盖该结构。
- **S 标配**：使用公共“用量”并计入单车合计；**O 选配**：展示单价但不计入标配合计；**- 不配**：用量为 0。
- 会议名称及日期完整的变更纳入预测，分配置优先取落地 Δ，否则取预算 Δ。
- **最新单车成本 = Cost BOM + 已决策且未计入 BOM 的变更 Δ**；通过变更号关联和覆盖检查避免重复计算。
- 单车 Δ 直接求和；零件单价 Δ 乘以对应装车用量。涨价填正数，降价填负数。
- 首页 Review 和配置明细按 **二级分类** 汇总，空分类归入“未分类”。

## 开发与验证

应用源码和离线交付物为 `dist/cost-bom-tool.html`。运行 `npm run build` 将其同步为部署首页 `dist/index.html`；两者均可独立离线运行。测试直接提取交付 HTML 内的脚本，避免测试到过期副本。

```bash
npm test
```

需要 Node.js 18 或以上版本，无第三方 npm 依赖。修改脚本后运行以下命令刷新 CSP 脚本哈希，再测试：

```bash
node scripts/check-standalone.cjs --update-csp
npm run build
npm test
```

- `tests/`：BOM 工作流、Δ 计算和二级分类回归检查。
- `scripts/`：单文件结构、脚本语法、CSP 检查。
- [`docs/STATUS.md`](docs/STATUS.md)：已实现范围、验证证据、待验收项。
- 早期内部设计稿与工作计划保留在本地，不纳入公开仓库；当前实现范围以代码和状态文档为准。

## 数据存储

工作区无需密码，打开后自动读取本机数据。工作区保存在浏览器 IndexedDB 中，JSON 备份、可读表格和周报均为明文。旧版加密数据保留在独立存储键中，不会被新工作区覆盖；导入旧数据仍需原密码。应用的 CSP 禁止外部连接和脚本资源。

仓库只保存代码、合成测试数据及文档，不包含实际 BOM、会议截图、上传文件或工作区备份。当前仍需使用脱敏原始 Excel 和目标公司浏览器验收；测试通过不等于已完成生产验收。
